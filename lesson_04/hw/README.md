# Операции с файлами и каталогами

В работе проверены команды `pwd`, `cd`, `mkdir`, `touch`, `ls`, `cat`, `cp`, `mv`, `rm`, `rmdir`, `cut`, `grep` и `find`.

Скрипт создаёт временный каталог, выполняет примеры и удаляет временные файлы после завершения. Результат запуска сохранён в [results.txt](results.txt).

Запуск:

```bash
chmod +x file-operations.sh
./file-operations.sh
```
