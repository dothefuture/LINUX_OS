# Диагностика сети в Linux

Каждая задача из практической работы находится в отдельном Bash-скрипте.

| № | Файл | Задача |
| --- | --- | --- |
| 1 | `01_interfaces.sh` | Интерфейсы, основной интерфейс, IP и MAC |
| 2 | `02_routes.sh` | Таблица маршрутов, шлюз и маршрут к 1.1.1.1 |
| 3 | `03_connectivity.sh` | Проверка шлюза, интернета и DNS |
| 4 | `04_traceroute.sh` | Трассировка до 8.8.8.8 |
| 5 | `05_listening_ports.sh` | Слушающие TCP-порты и SSH |
| 6 | `06_dns_resolver.sh` | Системный DNS и запрос через 8.8.8.8 |
| 7 | `07_create_dummy.sh` | Создание и настройка `dummy0` |
| 8 | `08_temporary_route.sh` | Добавление, проверка и удаление маршрута |
| 9 | `09_change_mac.sh` | Смена MAC-адреса `dummy0` |
| 10 | `10_neighbor_table.sh` | Neighbor/ARP-таблица и MAC шлюза |
| 11 | `11_profile_inventory.sh` | Профили NetworkManager и сетевые устройства |
| 12 | `12_profile_settings.sh` | Просмотр и сохранение настроек активного профиля |
| 13 | `13_add_dns.sh` | Временное добавление DNS `1.1.1.1` с откатом |
| 14 | `14_empty_profile.sh` | Создание неактивного тестового профиля |
| 15 | `15_autoconnect.sh` | Переключение параметра autoconnect |
| 16 | `16_dns_speed.sh` | Сравнение скорости DNS-серверов |
| 17 | `17_reverse_dns.sh` | Прямой и обратный DNS-запрос |
| 18 | `18_hosts_check.sh` | Временная запись в `/etc/hosts` с откатом |
| 19 | `19_network_namespace.sh` | Изолированный network namespace |
| 20 | `20_veth_pair.sh` | Соединение namespace и хоста через veth |
| 21 | `21_nc_port.sh` | Проверка TCP-порта через netcat |
| 22 | `22_curl_http.sh` | HTTP-запрос и проверка ответа через curl |

Запускать на Linux из этого каталога:

```bash
./01_interfaces.sh
```

Для задач 7–9 потребуется `sudo`. Их нужно запускать по порядку. После задачи 9 виртуальный интерфейс можно удалить командой:

```bash
./09_change_mac.sh --cleanup
```

Основные зависимости: `iproute2`, `iputils-ping`, `traceroute`, `dnsutils` (Ubuntu/Debian) или соответствующие пакеты используемого дистрибутива.

Задачи 13–15 и 18–20 также используют `sudo`. Все временные изменения в этих скриптах отменяются после проверки. Для задач 11–15 нужен NetworkManager (`nmcli`), для задачи 21 — `netcat`, для задачи 22 — `curl`.

В задаче 8 маршрут с метрикой `100` добавляется отдельно от connected-route, который Linux автоматически создаёт после назначения `10.99.0.1/24` интерфейсу `dummy0`. Скрипт удаляет только добавленный им маршрут и сохраняет рабочее состояние `dummy0`.
